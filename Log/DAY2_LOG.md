## Step 2. 데이터 분할

- 질문 : Hold-out 약 7셀로 Valid를 믿을 수 있을까?
- 내 예상 :
  - Batch 1 정책은 20개 정도이고 정책당 1~2셀이라, Hold-out은 정책 4개 정도가 된다.
  - 수명 분포(534~1074, CV 19%)를 보면 어떤 정책이 뽑히느냐에 따라 Hold-out이 장수명이나 단수명 쪽으로 치우칠 수 있다.
  - 7셀 중 1~2셀만 크게 틀려도 평균이 바로 움직이므로, seed에 따라 Valid MAPE가 ±3~5%p는 흔들릴 것 같다.
  - Valid 단일 수치만으로 비슷한 모델끼리 우열을 가리기는 어려울 것이다.
- 결과 :
  - 정책 단위 GroupShuffleSplit(test_size=0.2, random_state=42)으로 나눴다. Batch 1은 36셀·20정책이고, train은 29셀(정책 16개), Hold-out은 7셀(정책 4개)이다.
  - Hold-out 수명은 최소 617, 중앙값 870, 최대 1074, 평균 약 834다. Train은 최소 534, 중앙값 757, 최대 1054다.
  - Hold-out 4개 정책과 셀 수명은 다음과 같다.
    - 7C(40%)-3.6C: 617, 625
    - 8C(15%)-3.6C: 966, 1051
    - 4.4C(80%)-4.4C: 1074 (1셀)
    - 4.8C(80%)-4.8C: 636, 870
  - Hold-out 수명은 617~636 구간의 3셀과 870~1074 구간의 4셀로 나뉘고, 그 사이(636~870)에는 셀이 없다.
  - Hold-out 범위(617~1074)는 Batch 1 전체 범위(534~1074)의 약 85%를 덮는다. Batch 1 전체의 최댓값(1074)은 Hold-out에 들어갔고, 최솟값(534)은 train에 남았다.
  - 같은 정책 안에서도 수명 차이가 크다. 4.8C(80%)-4.8C는 636과 870으로 약 1.37배 차이가 난다.
  - 반복 분할(seed 0~19)에서 Hold-out 셀 수는 최소 6, 중앙값 7, 최대 8이었다. 서로 다른 Hold-out 조합이 20개 모두 나왔다.
- 해석 / 다음 판단 :
  - 예상 중 "정책 4개, 셀 약 7개"는 맞았다.
  - "장수명이나 단수명 쪽으로 치우칠 수 있다"는 이 seed에서는 뚜렷하게 확인되지 않았다.
    - Hold-out 중앙값(870)이 Train(757)보다 113 높고 최댓값도 Train보다 20 높다. 이것만 보면 장수명 쪽이다.
    - 하지만 7셀 중 3셀은 617~636의 단수명이고, 범위도 넓게 덮고 있어서 한쪽으로 쏠렸다고 보기는 어렵다.
    - 중앙값 차이는 7셀 중 몇 셀만 달라져도 바뀔 수준이다.
    - 다만 534~617 구간은 Hold-out에 없고, 1074는 Train 최댓값을 살짝 넘는 값이어서 Hold-out이 Train 범위를 거의 벗어나지는 않았다.
  - 정책 단위 분할이라 정책에 따라 셀 수가 6~8개로 달라지고, 한 정책이 1~2셀을 한꺼번에 가져간다. 셀 1개가 Valid MAPE 평균의 약 1/7(14%)을 차지하므로, 1~2셀의 오차가 평균을 크게 움직일 수 있는 구조는 확인됐다. 다만 "Valid MAPE가 seed에 따라 ±3~5%p 흔들린다"는 예상은 아직 검증되지 않았다.
  - 이 한 번의 분할로는 치우침 방향도, 변동 크기도 말할 수 없다. 그래서 Step 3의 Valid 수치는 잠정적으로 참고용으로만 보고, A와 B 같은 비슷한 모델의 우열은 Step 4의 20회 반복 표준편차와 비교한 뒤에 판단한다.

**H1 결과 해석**

- Valid 8.47은 예상(8~10%) 안이다. Batch 1 안에서는 log_var 하나로 약 10% 오차 수준이 나온다는 계산이 맞았다.
- Batch 2가 예상보다 나쁜 이유는 두 가지다.
  - old 30셀이 전부 과대예측됐고, log 잔차 중앙값이 +0.121이었다. 10^0.121 ≈ 1.32라서 예상한 오프셋(0.1, 약 26%)보다 조금 컸다. old MAPE 31.87이 예상 25%보다 높은 것과 맞는다.
  - new 9셀도 10% 안팎일 거라 봤지만 17.53이었고, 9셀 중 8셀이 과대예측이었다. new 셀도 "직선 근처"보다는 위쪽으로 치우쳐 있었다.
- Batch 3 12.81은 예상 범위 아래쪽이다. 노이즈 4셀을 빼면 11.75로 Batch 1 Valid와 3%p 정도 차이다. log_var 관계 자체는 Batch 3에도 꽤 그대로 옮겨간다.

**H2 결과 해석**

- 예상대로 정규화가 피처 하나에 몰아줬다. B_elasticnet 계수는 log_var -0.060, log_abs_min -0.003, dQ_mean 0이라서 사실상 log_var 단일 모델이다. B_ridge는 세 피처에 나눠 줬다(-0.026 / -0.020 / +0.016).
- 그런데도 seed 42에서 Valid가 A보다 1.8~2.9%p 나빴다. 같은 정보를 쓰는데 차이가 난 것은 정규화(alpha)로 기울기가 줄어든 영향과 Hold-out 7셀 구성 때문으로 본다. 20회 반복에서는 B_elasticnet − A 평균 +0.37%p(차이 std 2.00), B가 더 나은 seed는 8/20이라 둘은 구분이 안 된다.
- Batch 2·3에서도 A와 1~2%p 이내다. 보조 ΔQ 피처는 이득도 손해도 거의 없다. 같은 정보라는 DAY1 판단(VIF 23~183)이 맞았다.

**H3 결과 해석**

- 예상이 가장 크게 틀린 가설이다. 걱정했던 "부호가 뒤집히는 피처"는 ElasticNet(l1_ratio 0.9)이 거의 쓰지 않았다.
  - chargetime_2_6 계수 0.0001, fade_slope_2_100 0, QD_100_minus_2 0
  - 실제로 쓴 피처는 log_var(-0.083), QD_2(+0.022), QD_max_minus_2(-0.018), dQ_kurt(-0.006) 4개다.
  - 즉 "학습 전용 피처를 넣으면 나빠진다"가 아니라, L1이 그 피처를 걸러냈고 다른 피처(QD_2, QD_max_minus_2, dQ_kurt)가 들어갔다.
- Batch 2가 좋아진 것은 old 셀 때문이다. old MAPE가 A 31.87 → C 25.64로 내려갔다.
  - 피처별 log10 기여(계수 × z, Batch 1 평균 셀 대비)를 Batch 2 old 30셀 평균으로 분해하면 :
    - log_var -0.142 (A_linear는 -0.117), QD_2 +0.046, QD_max_minus_2 -0.042, dQ_kurt -0.002
    - QD_2와 QD_max_minus_2는 서로 거의 상쇄된다 (합 +0.004).
    - A 대비 줄어든 과대예측(log 잔차 평균 0.118 → 0.094, -0.024)은 거의 전부 **log_var 계수가 A보다 가팔라진 것**(-0.083 vs -0.068, 약 1.2배)에서 나왔다. 절편은 A·C 모두 2.8892로 같다.
  - 같은 이유로 new 셀은 나빠졌다. new 셀은 log_var가 작아(z 중앙값 -1.92) 가파른 기울기가 예측을 더 올린다 (log 잔차 평균 A 0.059 → C 0.093).
  - 즉 C의 Batch 2 old 개선은 "새 정보를 쓴 것"도, "부호 뒤집히는 피처가 큰 계수로 우연히 상쇄된 것"도 아니다. 다른 피처와 함께 학습하면서 log_var 기울기가 가팔라졌고, 그 기울기가 old에는 유리하고 new에는 불리하게 작용했다.
  - 단 QD_2, QD_max_minus_2 자체는 배치 일관 피처가 아니다 (log 수명 상관 QD_2 : 0.16 / -0.23 / 0.17, QD_max_minus_2 : 0.29 / -0.31 / 0.10). Batch 2 old에서 둘이 상쇄된 것은 우연일 수 있다.
- 반대로 new 셀은 나빠졌다 (A 17.53 → C 25.60). b2c44(841 → 1452 예측), b2c9(791 → 1217)가 크게 과대예측됐다.
- Batch 3은 노이즈 셀에서 크게 틀렸다 (아래 Step 6). dQ_kurt는 DAY1에서 "배치 간 불안정"으로 제외하려던 피처인데, Batch 3 장수명 셀에서 예측을 크게 끌어내렸다.
- 정리하면 H3의 방향(학습 배치 전용 정보는 위험하다)은 여전히 유효하다. 다만 위험이 Batch 2 평균 MAPE에서가 아니라 new 셀과 Batch 3 일부 셀에서 드러났다.

**H4 결과 해석**

- 트리 예측 범위는 B_rf 594~949, B_gbr 586~974로 학습 범위(534~1074) 안에 갇혔다. 외삽을 못 한다는 예상은 맞았다.
- Batch 3 : 1000 이상 셀을 950~975 근처로 눌러서 18%대로 선형(12%대)보다 확실히 나빴다.
- Batch 2 : 평균은 선형과 비슷했다. 구조별로 보면 이유가 보인다.
  - old : 트리 34.96 / 37.71 vs 선형 B 34.4 → 트리가 약간 더 나쁨 (예측 하한 약 590이 실제 392~514보다 높음)
  - new : 트리 12.78 / 11.52 vs 선형 B 15.8 → 트리가 더 좋음 (예측 상한이 낮아 과대예측이 줄어듦)
  - 즉 Batch 2에서는 선형도 old 셀을 전부 과대예측해서, "외삽 가능"의 이점이 나타나지 않았다. 외삽이 필요한 방향(더 짧은 수명)으로 선형이 충분히 내려가지 못했기 때문이다.

**H1 근거**

- Batch 1에서 log_var와 log 수명의 상관이 -0.84라서, 설명 못 하는 분산이 약 30%다.
- 그러면 log 잔차 표준편차가 0.04 정도이고, 수명으로 환산하면 10% 안팎이다.
- 그래서 Batch 1 안의 Valid는 8~10% 정도로 예상한다.
- Batch 2 기존 구조 30셀은 Batch 1 직선보다 log로 약 0.1 아래에 있었다. 10^0.1 ≈ 1.26이니까 약 25% 과대예측된다.
- newstructure 9셀은 직선 근처라 10% 안팎일 것이다.
- 가중평균하면 (30×25 + 9×10) / 39 ≈ 21%이므로 Batch 2는 20~25%로 예상한다.
- Batch 3은 상관이 -0.76으로 약간 약하고, 학습 범위 밖의 장수명 셀이 있어서 Batch 1보다는 나쁠 것이다.

**H2 근거**

- 세 피처끼리 상관이 0.97~0.996이고 VIF가 23~183이라 사실상 같은 정보다.
- ElasticNet이 1~2개 계수를 0 근처로 줄일 것이고, 성능 차이는 거의 없을 것이다.

**H3 근거**

- 충전시간과 용량 기울기는 Batch 1에서 상관이 0.55~0.58이라 Batch 1 안에서는 도움이 될 수 있다.
- 하지만 Batch 2에서는 부호가 뒤집혀서(충전시간 -0.94), 오히려 예측을 반대로 끌고 갈 것이다.
- Batch 2 MAPE가 B보다 몇 %p 이상 나빠질 것으로 예상한다.

**H4 근거**

- 트리는 학습 데이터 범위 밖으로 예측하지 못한다. 학습 최솟값 534 근처 아래로는 예측이 안 나온다.
- Batch 2 기존 구조 셀은 실제 392~514라서 오차가 최소 5~35%다.
- Batch 3에서 1500 이상인 셀도 1074 근처로 예측될 테니 30% 이상 틀릴 것이다.
- 이 셀들 때문에 Batch 2·3 모두 선형보다 나쁠 것으로 예상한다.

- 최종 모델 예상 :
  - A와 B의 Valid 차이가 1%p 이내일 것 같아서, 규칙상 더 단순한 A_linear가 선택될 것이다.
  - B가 확실히 나으면 B_ridge나 B_elasticnet을 고른다.
- 최종 모델 선택과 이유 : **C_elasticnet** (미리 정한 규칙대로)
  - 규칙 : Valid MAPE 최저, 1%p 이내면 더 단순한 모델. C가 5.61로 최저이고 2위 A_linear(8.47)와 2.86%p 차이라, 1%p 이내 모델이 없다.
  - Step 4에서 다시 확인했다. 20회 중 C가 1위 16회, A보다 낮은 seed 17/20, 평균 Valid 6.66 vs A 9.63이다. seed 42만의 우연은 아니다.
  - 예상(A_linear 선택)과 다르다. A와 B의 비교는 예상대로 구분이 안 됐지만, C가 Batch 1 안에서 확실히 나았다.
  - 단, 위험 요인을 함께 기록한다.
    - C의 Batch 2 old 개선은 log_var 기울기가 가팔라진 효과다. 같은 효과로 Batch 2 new는 A보다 나빠졌다 (17.53 → 25.60). 함께 쓰는 QD_2, QD_max_minus_2는 배치 간 부호가 뒤집히는 피처이고, Batch 2 old에서는 서로 상쇄됐다.
    - Batch 3 노이즈 셀과 장수명 셀에서 dQ_kurt 때문에 과소예측이 크다 (노이즈 4셀 MAPE 48.28).
    - Batch 2·3만 보면 A_linear(28.56 / 12.81)와 C(25.63 / 13.21)는 한쪽이 확실히 낫다고 하기 어렵다. 하지만 테스트 배치로 모델을 고르는 것은 규칙 위반이므로 선택 근거로 쓰지 않는다.

## Step 4. Hold-out 안정성

- 내 예상 :
  - 20회 반복하면 Valid MAPE 표준편차가 2~4%p 정도 나올 것이다.
  - 판단 기준을 미리 정한다. 표준편차가 A·B 간 Valid 차이보다 크면, Step 3의 Valid로 둘의 우열을 말할 수 없다고 보고 단순한 모델을 유지한다.
- 결과 :

  | 모델 | Valid 평균 ± std (20회) | min ~ max | 1위 횟수 | seed 42 Valid |
  | --- | --- | --- | --- | --- |
  | A_linear | 9.63 ± 2.55 | 5.09 ~ 15.87 | 3 | 8.47 |
  | B_ridge | 10.36 ± 2.65 | 6.09 ~ 16.33 | 0 | 11.41 |
  | B_elasticnet | 10.00 ± 2.48 | 6.18 ~ 15.54 | 0 | 10.31 |
  | C_elasticnet | 6.66 ± 2.95 | 2.22 ~ 16.29 | 16 | 5.61 |
  | B_rf | 11.29 ± 3.20 | 7.03 ~ 17.99 | 0 | 10.21 |
  | B_gbr | 11.19 ± 4.45 | 5.10 ~ 21.10 | 1 | 9.69 |

  - 같은 seed끼리 비교한 차이 : B_elasticnet − A +0.37 (std 2.00, B가 나은 seed 8/20), B_ridge − A +0.73 (std 1.99, 6/20), C − A -2.97 (std 3.37, 17/20), C − B_elasticnet -3.34 (std 2.92, 19/20)
  - 표준편차는 2.5~4.5%p로, 예상(2~4%p)과 거의 같다. GBR만 4.45로 조금 넘었다.
  - min~max 폭은 모델마다 9~16%p다. Step 2에서 예상한 "±3~5%p"보다 극단값은 더 넓다.
- Step 3 Valid 수치를 어느 정도 믿을 수 있나 :
  - 단일 Valid 값 하나는 ±2.5~3%p 흔들리는 값으로 봐야 한다. seed 42의 값은 대부분 20회 분포의 중간 근처였다 (A는 20회 중 7개 seed가 이보다 낮음, C는 9개).
  - 미리 정한 기준을 적용하면 :
    - A vs B : 평균 차이(0.37%p)가 표준편차(2.5%p)보다 훨씬 작다 → 우열을 말할 수 없음 → 단순한 A가 B보다 낫다고 본다. Step 3에서 B가 1.8~2.9%p 나빴던 것도 이 흔들림 범위 안이다.
    - C vs A : 평균 차이(2.97%p)가 표준편차와 비슷한 크기지만, 같은 seed끼리 비교하면 20회 중 17회 C가 낮다. 분할이 바뀌어도 C가 Batch 1 안에서 더 정확하다는 것은 믿을 만하다.
  - 결론 : Step 3 Valid의 "순위"는 C ≫ (A ≈ B) > 트리 정도로만 믿는다. 1~2%p 차이는 의미 없다.
  - 다만 이것은 Batch 1 안에서의 안정성이다. Valid가 좋아도 Batch 2·3에서는 C도 A와 비슷한 수준이었으므로, Valid는 배치가 바뀌었을 때의 성능을 보장하지 않는다.

## Step 5. 논문 조건 근사 재현 (H6)

- 내 예상 :
  - Batch 1+2를 섞어 학습하면 Batch 2 기존 구조 셀의 패턴을 학습할 수 있게 되므로, test MAPE가 우리 조건보다 크게 줄어 10~15% 정도가 될 것이다.
  - 그래도 9.1%까지는 못 갈 것 같다. 원인은 셋이다.
    - 이어붙인 장수명 셀 5개가 빠졌다.
    - 셀 인덱스가 달라서 분할이 원논문과 다르다.
    - 논문 full 모델보다 피처가 적다.
- 결과 :
  - 분할 : Batch 1+2 75셀을 cell_id(배치, 셀 번호) 순으로 정렬해 교대 배정 → train 38셀(b1 18 / b2 20), test 37셀(b1 18 / b2 19). Batch 3은 secondary.
  - 완전 재현이 아닌 근사다 (b1c0~c4 이어붙인 셀 없음, 셀 인덱스 다름).

  | 조건 | 모델 | Train CV | Test | Test 중 b1 셀 | Test 중 b2 셀 | Batch 3 |
  | --- | --- | --- | --- | --- | --- | --- |
  | 논문식 | C_elasticnet | 11.03 | 13.74 | 9.45 | 17.81 | 15.68 |
  | 우리 | C_elasticnet | 5.91 | 25.63 (B2) | – | 25.63 | 13.21 |
  | 논문식 | A_linear | 15.61 | 13.19 | 10.86 | 15.39 | 13.12 |
  | 우리 | A_linear | 8.87 | 28.56 (B2) | – | 28.56 | 12.81 |

  - 예상(test 10~15%, 9.1%에는 못 미침)은 맞았다. C 13.74, A 13.19.
  - test 37셀 중 35셀은 같은 정책이 train에도 있다.
  - 논문식에서는 A_linear가 C보다 test·Batch 3 모두 약간 좋다. C는 test에서 train 최소 수명(393)보다 낮게 예측한 셀이 6개 있었다 (b2c17 : 실제 471, 예측 235).
- 논문과의 차이 중 분할 조건 때문인 부분 / 나머지 :
  - C 기준으로 Target(9.1%)과의 차이 16.5%p 중 약 11.9%p(25.63 → 13.74)가 분할 조건을 바꾸자 사라졌고, 약 4.6%p(13.74 → 9.1)가 남는다. A 기준으로는 15.4%p가 줄고 4.1%p가 남는다.
  - 그런데 이 11.9%p를 전부 "분할 조건 효과"로 볼 수는 없다. 논문식 test에는 쉬운 Batch 1 셀이 절반(18셀) 섞여 있기 때문이다. Batch 2 셀만 비교하면 :
    - C : 25.63 → 17.81 (-7.8%p), A : 28.56 → 15.39 (-13.2%p)
    - 즉 Batch 2를 학습에 넣어 "Batch 2 셀을 맞히는 능력"이 좋아진 부분은 7.8~13.2%p이고, 나머지는 test 구성이 쉬워진 효과다.
  - 남은 4~5%p의 원인 후보 (이번 실험으로는 나눠서 측정하지 못함) :
    - 데이터 : 학습 셀 수 차이와 이어붙인 장수명 셀 5개(b1c0~c4) 부재
    - 분할 : 셀 인덱스가 달라 같은 교대 분할이라도 셀 배정이 원논문과 다름
    - 피처 : 원논문 모델과 피처 구성이 다름 (논문 Table 1 수치를 원문에서 확인한 뒤 모델별로 비교 필요)
  - 정리 : 원논문 수준의 MAPE는 "Batch 2 정보를 학습에 쓴 조건"에서 나온 값이고, 우리 조건(다른 배치로 평가)의 25~29%와 직접 비교하면 안 된다. 같은 정책이 train·test에 함께 들어가는 점(35/37셀)도 원논문 조건이 더 쉬운 이유 중 하나다.

## Step 6. 오류 분석 (H5)

- 내 예상 (오차가 큰 셀) :
  - 오차 상위 10셀 중 6~8개는 Batch 2 기존 구조 셀이고, 모두 과대예측일 것이다.
  - 나머지는 Batch 3에서 log_var가 아주 작은 장수명 셀(학습 범위 밖)일 것이다.
  - Batch 3 노이즈 셀(c2, c37, c42, c43) 중 2개는 Q3에서 직선과 꽤 떨어져 있었으므로, 이들을 빼면 Batch 3 MAPE가 조금 좋아질 것이다.
- 결과 :
  - Batch 2 구조별 MAPE (old 30셀 / new 9셀)

    | 모델 | old | old 과대예측 | new | new 과대예측 |
    | --- | --- | --- | --- | --- |
    | A_linear | 31.87 | 30/30 | 17.53 | 8/9 |
    | B_elasticnet | 34.41 | 30/30 | 15.79 | 6/9 |
    | C_elasticnet | 25.64 | 28/30 | 25.60 | 8/9 |
    | B_rf | 34.96 | 30/30 | 12.78 | 5/9 |

  - Batch 3 노이즈 셀 포함 / 제외 : A_linear 12.81 → 11.75, B_elasticnet 12.34 → 11.59, C_elasticnet 13.21 → 9.71 (노이즈 4셀만 48.28)
  - 오차 상위 10셀 구성 (Batch 2·3)
    - C_elasticnet : B2 old 과대 4, B2 new 과대 2, B3 new 과소 4 / 학습 log_var 범위(-4.179 ~ -3.350) 밖 8셀
    - A_linear : B2 old 과대 8, B2 new 과대 1, B3 new 과소 1 / 범위 밖 4셀
  - C 상위 셀 : b2c44(841 → 1452), b3c42(1642 → 472), b3c37(1390 → 581), b2c9(791 → 1217), b3c38(1935 → 1235), b3c2(1267 → 821)
  - 학습 log_var 범위 밖 셀 : Batch 2 아래 6 / 위 11 (39셀 중), Batch 3 아래 21 / 위 0 (44셀 중)
- 해석 :
  - 예상 "상위 10셀 중 6~8개는 Batch 2 old 과대예측"은 A_linear에서는 맞았다(8개). C에서는 4개로 줄었고, 그 자리를 Batch 3 과소예측과 Batch 2 new 과대예측이 채웠다.
  - **H5 (Batch 2 오차는 셀 구조 차이에서 오는가)** : A·B·트리 모델에서는 그렇다.
    - old MAPE가 new의 약 2~3배이고, old 30셀이 전부 과대예측이다. 같은 log_var에서 old 셀의 실제 수명이 더 짧다는 Q3 관찰이 그대로 오차가 됐다.
    - old 셀 log_var는 학습 범위 위쪽(-3.35 이상)으로 11셀이 벗어나 있어서, 피처 축 외삽도 겹친다.
    - C에서는 old·new MAPE가 25.6으로 같아졌지만, 구조 효과가 사라진 것이 아니다. C는 log_var 기울기가 A보다 가팔라서 old(큰 log_var)는 예측이 낮아져 좋아지고, new(작은 log_var)는 예측이 높아져 나빠진 결과 평균이 비슷해진 것이다.
  - 예상 "나머지는 Batch 3에서 log_var가 아주 작은 장수명 셀"도 맞았다. C 상위의 Batch 3 4셀은 모두 log_var -4.34 ~ -5.10으로 학습 범위 아래이고, 전부 과소예측이다.
    - 단 원인은 log_var 외삽 자체보다 dQ_kurt였다. 이 셀들에서 log_var는 예측을 +0.20 ~ +0.47(log10) 올렸는데, dQ_kurt가 -0.32 ~ -0.46 끌어내렸다. 즉 log_var는 "장수명"이라고 맞게 말했고, 배치 간 불안정한 dQ_kurt가 그것을 뒤집었다.
  - 예상 "노이즈 셀을 빼면 Batch 3이 조금 좋아진다"는 A·B에서는 맞았다(약 1%p). C에서는 3.5%p나 좋아졌다. 노이즈 4셀(c2, c37, c42, c43) 모두 C에서 28~71% 과소예측이었다. 노이즈 셀은 C처럼 kurtosis 같은 곡선 모양 통계량을 쓰는 모델에 특히 취약하다.
  - 정리 :
    - Batch 2의 주된 오차 원인은 셀 구조(old)이고, 이는 Batch 1에 old 구조만 있어 학습에서 보정할 방법이 없다.
    - Batch 3의 큰 오차는 학습 범위 밖 장수명 셀 + 노이즈 셀에서 나오고, C에서는 dQ_kurt가 증폭시킨다.
    - C의 Valid 우위는 Batch 1 안에서는 확실하지만(Step 4), 테스트 배치에서는 Batch 2 old를 줄인 대신 new와 Batch 3에서 새 오차를 만들었다. 배치 일관성으로 피처를 고르자는 DAY1 판단의 근거가 다시 확인됐다.

## 오늘 막혔던 것 / 새로 알게 된 것

- `TransformedTargetRegressor(inverse_func=lambda y: 10**y)`로 저장한 모델은 `python -m`으로 실행하면 joblib 로드가 깨졌다. lambda·모듈 함수가 `__main__`에 묶이기 때문이다. `partial(np.power, 10.0)`으로 바꿔 해결했다 (결과 수치는 동일).
- ElasticNet(L1)은 "학습 배치 전용 피처"를 알아서 걸러냈지만, 대신 다른 불안정 피처(QD_2, QD_max_minus_2, dQ_kurt)를 골랐다. 20회 반복 재학습에서도 QD_2·QD_max_minus_2는 20/20, dQ_kurt는 14/20 선택됐다. 정규화가 피처 선택을 대신해 주지는 않는다. 배치 일관성 기준의 사전 피처 선택이 여전히 필요하다.
- Valid 7셀 MAPE는 seed에 따라 표준편차 2.5~4.5%p로 흔들린다. 1~2%p 차이로 모델을 고르면 안 되고, 반복 분할로 확인해야 한다.
- 논문 성능과 비교할 때는 분할 조건뿐 아니라 test 구성(쉬운 Batch 1 셀 포함 여부)까지 맞춰서 봐야 한다.
