# DAY2 실험 기록

## Step 2. 데이터 분할

- 질문 : Hold-out 약 7셀로 Valid를 믿을 수 있을까?
- 내 예상 :
  - Batch 1 정책은 20개 정도이고 정책당 1~2셀이라, Hold-out은 정책 4개 정도가 된다.
  - 수명 분포(534~1074, CV 19%)를 보면 어떤 정책이 뽑히느냐에 따라 Hold-out이 장수명이나 단수명 쪽으로 치우칠 수 있다.
  - 7셀 중 1~2셀만 크게 틀려도 평균이 바로 움직이므로, seed에 따라 Valid MAPE가 ±3~5%p는 흔들릴 것 같다.
  - Valid 단일 수치만으로 비슷한 모델끼리 우열을 가리기는 어려울 것이다.
- 결과 :
  - 정책 단위 GroupShuffleSplit(test_size=0.2, random_state=42)으로 나눴다. Batch 1은 36셀·20정책이고, train은 29셀(정책 16개), Hold-out은 7셀(정책 4개)이다.
  - Hold-out 수명은 최소 617, 중앙값 870, 최대 1074, 평균 약 834다. Train은 최소 534, 중앙값 757, 최대 1054다.
  - Hold-out 4개 정책과 셀 수명은 다음과 같다.
    - 7C(40%)-3.6C: 617, 625
    - 8C(15%)-3.6C: 966, 1051
    - 4.4C(80%)-4.4C: 1074 (1셀)
    - 4.8C(80%)-4.8C: 636, 870
  - Hold-out 수명은 617~636 구간의 3셀과 870~1074 구간의 4셀로 나뉘고, 그 사이(636~870)에는 셀이 없다.
  - Hold-out 범위(617~1074)는 Batch 1 전체 범위(534~1074)의 약 85%를 덮는다. Batch 1 전체의 최댓값(1074)은 Hold-out에 들어갔고, 최솟값(534)은 train에 남았다.
  - 같은 정책 안에서도 수명 차이가 크다. 4.8C(80%)-4.8C는 636과 870으로 약 1.37배 차이가 난다.
  - 반복 분할(seed 0~19)에서 Hold-out 셀 수는 최소 6, 중앙값 7, 최대 8이었다. 서로 다른 Hold-out 조합이 20개 모두 나왔다.
- 해석 / 다음 판단 :
  - 예상 중 "정책 4개, 셀 약 7개"는 맞았다.
  - "장수명이나 단수명 쪽으로 치우칠 수 있다"는 이 seed에서는 뚜렷하게 확인되지 않았다.
    - Hold-out 중앙값(870)이 Train(757)보다 113 높고 최댓값도 Train보다 20 높다. 이것만 보면 장수명 쪽이다.
    - 하지만 7셀 중 3셀은 617~636의 단수명이고, 범위도 넓게 덮고 있어서 한쪽으로 쏠렸다고 보기는 어렵다.
    - 중앙값 차이는 7셀 중 몇 셀만 달라져도 바뀔 수준이다.
    - 다만 534~617 구간은 Hold-out에 없고, 1074는 Train 최댓값을 살짝 넘는 값이어서 Hold-out이 Train 범위를 거의 벗어나지는 않았다.
  - 정책 단위 분할이라 정책에 따라 셀 수가 6~8개로 달라지고, 한 정책이 1~2셀을 한꺼번에 가져간다. 셀 1개가 Valid MAPE 평균의 약 1/7(14%)을 차지하므로, 1~2셀의 오차가 평균을 크게 움직일 수 있는 구조는 확인됐다. 다만 "Valid MAPE가 seed에 따라 ±3~5%p 흔들린다"는 예상은 아직 검증되지 않았다.
  - 이 한 번의 분할로는 치우침 방향도, 변동 크기도 말할 수 없다. 그래서 Step 3의 Valid 수치는 잠정적으로 참고용으로만 보고, A와 B 같은 비슷한 모델의 우열은 Step 4의 20회 반복 표준편차와 비교한 뒤에 판단한다.

**H1 근거**

- Batch 1에서 log_var와 log 수명의 상관이 -0.84라서, 설명 못 하는 분산이 약 30%다.
- 그러면 log 잔차 표준편차가 0.04 정도이고, 수명으로 환산하면 10% 안팎이다.
- 그래서 Batch 1 안의 Valid는 8~10% 정도로 예상한다.
- Batch 2 기존 구조 30셀은 Batch 1 직선보다 log로 약 0.1 아래에 있었다. 10^0.1 ≈ 1.26이니까 약 25% 과대예측된다.
- newstructure 9셀은 직선 근처라 10% 안팎일 것이다.
- 가중평균하면 (30×25 + 9×10) / 39 ≈ 21%이므로 Batch 2는 20~25%로 예상한다.
- Batch 3은 상관이 -0.76으로 약간 약하고, 학습 범위 밖의 장수명 셀이 있어서 Batch 1보다는 나쁠 것이다.

**H2 근거**

- 세 피처끼리 상관이 0.97~0.996이고 VIF가 23~183이라 사실상 같은 정보다.
- ElasticNet이 1~2개 계수를 0 근처로 줄일 것이고, 성능 차이는 거의 없을 것이다.

**H3 근거**

- 충전시간과 용량 기울기는 Batch 1에서 상관이 0.55~0.58이라 Batch 1 안에서는 도움이 될 수 있다.
- 하지만 Batch 2에서는 부호가 뒤집혀서(충전시간 -0.94), 오히려 예측을 반대로 끌고 갈 것이다.
- Batch 2 MAPE가 B보다 몇 %p 이상 나빠질 것으로 예상한다.

**H4 근거**

- 트리는 학습 데이터 범위 밖으로 예측하지 못한다. 학습 최솟값 534 근처 아래로는 예측이 안 나온다.
- Batch 2 기존 구조 셀은 실제 392~514라서 오차가 최소 5~35%다.
- Batch 3에서 1500 이상인 셀도 1074 근처로 예측될 테니 30% 이상 틀릴 것이다.
- 이 셀들 때문에 Batch 2·3 모두 선형보다 나쁠 것으로 예상한다.

**H1 결과 해석 : Batch 1 안에서는 예상대로, Batch 2에서는 절편이 이동했다**

- Valid 8.47%는 예상(8~10%) 안이다. 상관 -0.84에서 계산한 "log 잔차 약 0.04 → 오차 약 10%"가 맞았다.
- Batch 2(28.56%)는 예상보다 3~8%p 나빴다. old 30셀의 log 잔차 중앙값이 +0.121(약 32% 과대)로, 내가 잡은 오프셋 0.1(약 26%)보다 컸다. new 9셀도 직선 근처가 아니라 8셀이 과대예측돼 17.53%였다.
- Batch 3(12.81%)은 예상 범위 아래쪽이고, 노이즈 4셀을 빼면 11.75%다.
- log_var와 수명의 관계는 "방향"은 배치를 넘어 유지되지만, 셀 구조가 바뀌면 "절편"이 이동한다.

**H2 결과 해석 : 보조 ΔQ 피처는 이득도 손해도 없다**

- B_elasticnet은 계수를 log_var(-0.060)에 몰고 log_abs_min(-0.003), dQ_mean(0)은 거의 버렸다. 사실상 log_var 단일 모델이다.
- seed 42에서는 Valid가 A보다 1.8~2.9%p 나빴지만, 20회 반복 평균 차이는 +0.37~0.73%p이고 B가 나은 seed는 6~8/20이다. Step 4 기준으로 구분할 수 없다.
- Batch 2·3에서도 A와 1~2%p 이내다. DAY1의 "세 피처는 같은 정보(VIF 23~183)" 판단이 맞았다.

**H3 결과 해석 : 가장 크게 빗나간 예상**

- 예상과 반대로 Valid 5.61%(최저), Batch 2 25.63%(B보다 4.5%p 좋음)였고, Batch 3만 0.9%p 나빴다.
- 빗나간 이유 1 : 내가 걱정한 충전시간·용량 기울기는 L1이 0으로 만들었다 (chargetime_2_6 0.0001, fade_slope_2_100 0). 실제로 쓴 피처는 log_var(-0.083), QD_2(+0.022), QD_max_minus_2(-0.018), dQ_kurt(-0.006)다.
- 빗나간 이유 2 : Batch 2 old 개선은 새 피처가 아니라 log_var 기울기에서 나왔다. 다른 피처와 함께 학습하면서 log_var 계수가 A보다 약 1.2배 가팔라졌고(-0.083 vs -0.068), old 셀 log 잔차가 0.118 → 0.094로 줄었다. QD_2(+0.046)와 QD_max_minus_2(-0.042)는 old 셀에서 서로 상쇄됐다.
- 같은 기울기가 new 셀에는 불리했다 (17.53 → 25.59, b2c44 841 → 1452). Batch 3 노이즈 셀은 dQ_kurt가 예측을 끌어내렸다.
- "학습 배치 전용 정보는 위험하다"는 방향은 맞았다. 다만 위험은 Batch 2 평균이 아니라 처음 보는 유형의 셀(new, Batch 3 일부)에서 드러났고, L1은 내가 걱정한 피처 대신 다른 불안정 피처(QD_2, QD_max_minus_2, dQ_kurt)를 골랐다.

**H4 결과 해석 : 반만 맞았다**

- 트리의 Batch 2·3 예측은 586~974로 학습 수명 범위(534~1074) 안에 갇혔다.
- Batch 3 : 실제 1000 이상 23셀을 836~974로 눌러 18%대로, 선형(12%대)보다 확실히 나빴다 → 예상대로.
- Batch 2 : 선형과 비슷했다 (29.84~31.67 vs 30.11). old는 트리가 약간 나쁘고(34.96~37.71 vs 34.41), new는 트리가 더 좋다(11.51~12.78 vs 15.79).
- 선형도 old 셀을 전부 과대예측해서 "외삽 가능"의 이점이 나타나지 않았다. 선형의 외삽은 관계의 절편이 유지될 때만 이점이다.

  - A와 B의 Valid 차이가 1%p 이내일 것 같아서, 규칙상 더 단순한 A_linear가 선택될 것이다.

  - 우연이 아니다. Step 4에서 C는 20회 중 1위 16회, A보다 낮은 seed 17/20이었다.
  - 테스트 결과로 규칙을 바꾸지 않았다. Batch 3 노이즈 셀 48%, Batch 2 new 25.6%는 테스트를 본 뒤에 안 사실이라 모델 교체 근거로 쓰면 "테스트로 모델 고르기"가 된다.
  - A를 기준 모델로 함께 보고한다. 평균 성능은 C가 낫지만, 처음 보는 셀에 대한 강건성은 A가 낫다 (노이즈 4셀 MAPE C 48.28 vs A 23.48, Batch 2 new C 25.59 vs A 17.53).
  - 예상(A 선택)과 달라진 이유 : A·B는 예상대로 구분이 안 됐지만, C가 Batch 1 안에서 확실히 나았다.

## Step 4. Hold-out 안정성

- 내 예상 :
  - 20회 반복하면 Valid MAPE 표준편차가 2~4%p 정도 나올 것이다.
  - 판단 기준을 미리 정한다. 표준편차가 A·B 간 Valid 차이보다 크면, Step 3의 Valid로 둘의 우열을 말할 수 없다고 보고 단순한 모델을 유지한다.
- 결과 :

  | A_linear     | 9.63 ± 2.55             | 5.09 ~ 15.87 | 3        | 8.47          |
  | B_ridge      | 10.36 ± 2.65            | 6.09 ~ 16.33 | 0        | 11.41         |
  | B_elasticnet | 10.00 ± 2.48            | 6.18 ~ 15.54 | 0        | 10.31         |
  | C_elasticnet | 6.66 ± 2.95             | 2.22 ~ 16.29 | 16       | 5.61          |
  | B_rf         | 11.29 ± 3.20            | 7.03 ~ 17.99 | 0        | 10.21         |
  | B_gbr        | 11.19 ± 4.45            | 5.10 ~ 21.10 | 1        | 9.69          |
  - 같은 seed끼리 비교한 차이 : B_elasticnet − A +0.37 (std 2.00, B가 나은 seed 8/20), B_ridge − A +0.73 (std 1.99, 6/20), C − A -2.97 (std 3.37, 17/20), C − B_elasticnet -3.34 (std 2.92, 19/20)
  - 표준편차는 2.5~4.5%p로, 예상(2~4%p)과 거의 같다. GBR만 4.45로 조금 넘었다.
  - min~max 폭은 모델마다 9~16%p다. Step 2에서 예상한 "±3~5%p"보다 극단값은 더 넓다.

- Step 3 Valid 수치를 어느 정도 믿을 수 있나 :
  - 단일 Valid는 ±2.5~3%p 흔들리는 값이다. seed 42의 값은 20회 분포의 중간 근처였다 (A는 7/20 seed가 더 낮음, C는 9/20).
  - 미리 정한 기준을 적용했다.
    - A vs B : 평균 차이 0.37%p가 표준편차 2.5%p보다 훨씬 작다 → 구분 불가 → 단순한 A를 유지한다. Step 3에서 B가 1.8~2.9%p 나빴던 것도 이 흔들림 안이다.
    - C vs A : 평균 차이 2.97%p이고, 같은 seed끼리 비교하면 17/20에서 C가 낮다 → 분할이 바뀌어도 C의 우위는 유지된다.
  - 믿을 수 있는 순위는 "C ≫ A ≈ B > 트리"까지다. 1~2%p 차이는 의미 없다.
  - 이것은 Batch 1 안에서의 안정성일 뿐이다. Valid 우위(C 6.66 vs A 9.63)는 Batch 2·3에서 거의 사라졌다 (25.63 vs 28.56, 13.21 vs 12.81).

## Step 5. 논문 조건 근사 재현 (H6)

- 내 예상 :
  - Batch 1+2를 섞어 학습하면 Batch 2 기존 구조 셀의 패턴을 학습할 수 있게 되므로, test MAPE가 우리 조건보다 크게 줄어 10~15% 정도가 될 것이다.
  - 그래도 9.1%까지는 못 갈 것 같다. 원인은 셋이다.
    - 이어붙인 장수명 셀 5개가 빠졌다.
    - 셀 인덱스가 달라서 분할이 원논문과 다르다.
    - 논문 full 모델보다 피처가 적다.
- 결과 :
  - 분할 : Batch 1+2 75셀을 cell_id(배치, 셀 번호) 순으로 정렬해 교대 배정 → train 38셀(b1 18 / b2 20), test 37셀(b1 18 / b2 19). Batch 3은 secondary.
  - 완전 재현이 아닌 근사다 (b1c0~c4 이어붙인 셀 없음, 셀 인덱스 다름).

  - test 37셀 중 35셀은 같은 정책이 train에도 있다.
  - 논문식에서는 A_linear가 C보다 test·Batch 3 모두 약간 좋다. C는 test에서 train 최소 수명(393)보다 낮게 예측한 셀이 6개 있었다 (b2c17 : 실제 471, 예측 235).

- 논문과의 차이 중 분할 조건 때문인 부분 / 나머지 :
  - C 기준 Target(9.1%)과의 차이 16.5%p를 세 단계로 나눴다.

    | 단계                      | MAPE  | 줄어든 폭 | 원인                                      |
    | ------------------------- | ----- | --------- | ----------------------------------------- |
    | 우리 조건 Batch 2         | 25.63 | –         |                                           |
    | 논문식 test 중 Batch 2 셀 | 17.81 | 7.8%p     | 분할 조건 (Batch 2 셀 절반을 학습에 포함) |
    | 논문식 test 전체          | 13.74 | 4.1%p     | test 구성 (쉬운 Batch 1 셀이 절반)        |
    | Target                    | 9.1   | 4.6%p     | 나머지 (분리 못 함)                       |

  - A 기준으로는 13.2%p(분할) + 2.2%p(test 구성) + 4.1%p(나머지)다.
  - 주의 : 1단계는 우리 조건 39셀과 논문식 test의 Batch 2 19셀을 비교해 셀 집합이 다르다. 같은 19셀끼리 비교하면 C 22.82 → 17.81(5.0%p), A 28.52 → 15.39(13.1%p)다. C의 7.8%p 중 약 2.8%p는 셀 집합 차이다.
  - 나머지 4~5%p의 후보는 예상에 적은 세 가지(이어붙인 장수명 셀 5개 부재, 셀 인덱스 차이, 피처 구성 차이)다. 이번 실험으로는 나눠서 측정하지 못했다.
  - 원논문 9.1%는 같은 배치·같은 정책이 train과 test에 함께 있는 조건(test 35/37셀이 train과 정책 공유)의 수치다. 처음 보는 배치로 평가한 우리 결과(25~29%)와 직접 비교하면 안 되고, 차이의 대부분은 모델이 아니라 평가 조건에서 온다.
  - 논문식 조건에서는 A가 C보다 약간 좋았다 (test 13.19 vs 13.74, Batch 3 13.12 vs 15.68). C의 이점은 학습 조건에 민감하다.

## Step 6. 오류 분석 (H5)

- 내 예상 (오차가 큰 셀) :
  - 오차 상위 10셀 중 6~8개는 Batch 2 기존 구조 셀이고, 모두 과대예측일 것이다.
  - 나머지는 Batch 3에서 log_var가 아주 작은 장수명 셀(학습 범위 밖)일 것이다.
  - Batch 3 노이즈 셀(c2, c37, c42, c43) 중 2개는 Q3에서 직선과 꽤 떨어져 있었으므로, 이들을 빼면 Batch 3 MAPE가 조금 좋아질 것이다.
- 결과 :
  - Batch 2 구조별 MAPE (old 30셀 / new 9셀)

    | 모델         | old   | old 과대예측 | new   | new 과대예측 |
    | ------------ | ----- | ------------ | ----- | ------------ |
    | A_linear     | 31.87 | 30/30        | 17.53 | 8/9          |
    | B_elasticnet | 34.41 | 30/30        | 15.79 | 6/9          |
    | C_elasticnet | 25.64 | 28/30        | 25.59 | 8/9          |
    | B_rf         | 34.96 | 30/30        | 12.78 | 5/9          |

  - Batch 3 노이즈 셀 포함 / 제외 : A_linear 12.81 → 11.75, B_elasticnet 12.34 → 11.59, C_elasticnet 13.21 → 9.71 (노이즈 4셀만 48.28)
  - 오차 상위 10셀 구성 (Batch 2·3)
    - C_elasticnet : B2 old 과대 4, B2 new 과대 2, B3 new 과소 4 / 학습 log_var 범위(-4.179 ~ -3.350) 밖 8셀
    - A_linear : B2 old 과대 8, B2 new 과대 1, B3 new 과소 1 / 범위 밖 4셀
  - C 상위 셀 : b2c44(841 → 1452), b3c42(1642 → 472), b3c37(1390 → 581), b2c9(791 → 1217), b3c38(1935 → 1235), b3c2(1267 → 821)
  - 학습 log_var 범위 밖 셀 : Batch 2 아래 6 / 위 11 (39셀 중), Batch 3 아래 21 / 위 0 (44셀 중)

- 해석 :
  - 예상 점검
    - "상위 10셀 중 6~8개는 Batch 2 old 과대예측" → A에서는 맞았다(8개). C에서는 4개였다.
    - "나머지는 Batch 3의 학습 범위 밖 장수명 셀" → 맞았다. C 상위의 Batch 3 4셀은 모두 log_var -4.34 ~ -5.10(학습 범위 아래)이고 전부 과소예측이다.
    - "노이즈 셀을 빼면 Batch 3이 조금 좋아짐" → A·B는 맞았다(약 1%p). C는 3.5%p로 예상보다 컸다.
  - **H5 (Batch 2 오차는 셀 구조에서 오는가) : 그렇다.**
    - A·B·트리 모두 old MAPE가 new의 1.8~3.3배이고, old 30셀이 전부 과대예측이다. Q3에서 본 "같은 log_var에서 old 셀의 수명이 더 짧다"가 그대로 오차가 됐다.
    - Batch 2 39셀 중 11셀은 log_var가 학습 범위 위쪽(> -3.35)이라 피처 축 외삽도 겹친다.
    - C에서 old·new MAPE가 같아진 것(25.6)은 구조 효과가 사라진 게 아니다. 가파른 log_var 기울기가 old 예측은 낮추고 new 예측은 올려 평균이 비슷해진 것이다.
  - **Batch 3 상위 4셀 중 3셀은 dQ_kurt, 1셀은 log_var 관계의 한계 때문이었다.**
    - b3c42, c37, c2(모두 원논문 노이즈 셀) : log_var는 예측을 +0.20 ~ +0.47(log10) 올려 "장수명"을 맞게 가리켰고, dQ_kurt가 -0.32 ~ -0.46 끌어내렸다.
    - b3c38(실제 1935) : dQ_kurt 영향은 -0.007로 거의 없다. log_var 기여(+0.20)가 필요한 값(+0.40)의 절반이라 log_var 관계 자체가 이 수명을 설명하지 못한다. A_linear도 1130으로 예측했다.
    - 노이즈 4셀은 C에서 28~71% 과소예측됐다. 곡선 모양 통계량(kurtosis)은 측정 노이즈에 민감하다.
  - 정리 : Batch 2 오차는 학습에 없던 셀 구조, Batch 3 오차는 범위 밖 장수명·노이즈 셀과 불안정 피처에서 나온다. 둘 다 "학습 배치에서 본 적 없는 유형의 셀"에서 생긴 오차다.

## 오늘 막혔던 것 / 새로 알게 된 것

- `TransformedTargetRegressor(inverse_func=lambda y: 10**y)`로 저장한 모델은 `python -m`으로 실행하면 joblib 로드가 깨졌다. lambda·모듈 함수가 `__main__`에 묶이기 때문이다. `partial(np.power, 10.0)`으로 바꿔 해결했다 (결과 수치는 동일).
- ElasticNet(L1)은 "학습 배치 전용 피처"를 알아서 걸러냈지만, 대신 다른 불안정 피처(QD_2, QD_max_minus_2, dQ_kurt)를 골랐다. 20회 반복 재학습에서도 QD_2·QD_max_minus_2는 20/20, dQ_kurt는 14/20 선택됐다. 정규화가 피처 선택을 대신해 주지는 않는다. 배치 일관성 기준의 사전 피처 선택이 여전히 필요하다.
- Valid 7셀 MAPE는 seed에 따라 표준편차 2.5~4.5%p로 흔들린다. 1~2%p 차이로 모델을 고르면 안 되고, 반복 분할로 확인해야 한다.
- 논문 성능과 비교할 때는 분할 조건뿐 아니라 test 구성(쉬운 Batch 1 셀 포함 여부)까지 맞춰서 봐야 한다.
